# 配置说明

## 后端
配置来源：`backend/src/main/resources/application.yaml`

当前可见配置：
- `spring.profiles.active: local`
- 默认安全用户（仅框架默认配置）：`admin/123456`

说明：
- JWT、数据库等实际运行参数按本地环境配置。
- 敏感信息不得提交到仓库。

## 前端
配置来源：`frontend/.env*`

- `VITE_API_BASE_URL`：后端 API 基础地址。
- 未设置时默认：`http://localhost:8080/api`（见 `frontend/src/api/http.js`）。
