# 需求说明

## 用户与认证
- 支持注册、登录、修改密码。
- 登录后访问受保护接口需携带 `Authorization: Bearer <token>`。
- 未登录访问受保护接口返回 401。

## 待办事项
- 字段：标题、描述、完成状态、重要标记、截止日期、创建时间、更新时间。
- 支持：列表、详情、新增、编辑、切换完成状态、删除。
- 只允许操作当前登录用户的数据。

## 前端页面
- 登录页 `/login`
- 注册页 `/register`
- 任务页 `/todos`
- 修改密码页 `/change-password`

## 非目标
- 不包含管理员、协作、分享、消息提醒、部署流水线等扩展功能。
