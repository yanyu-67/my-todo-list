# 认证接口

## 1) 注册
- `POST /api/auth/register`
- 请求体：`username`、`password`
- 成功：`201`

## 2) 登录
- `POST /api/auth/login`
- 请求体：`username`、`password`
- 成功返回：`token`、`username`

## 3) 修改密码
- `POST /api/auth/change-password`（需登录）
- 请求体：`oldPassword`、`newPassword`、`confirmPassword`
- 规则：
  - 旧密码必须正确
  - 新密码与确认密码一致
  - 新密码不能与旧密码相同

以上行为对应实现：`backend/src/main/java/com/yanyu/todo/service/AuthService.java`。
