# 任务接口

## 接口列表
- `GET /api/todos`：任务列表
- `GET /api/todos/{id}`：任务详情
- `POST /api/todos`：创建任务
- `PUT /api/todos/{id}`：更新任务
- `PATCH /api/todos/{id}/complete`：切换完成状态
- `DELETE /api/todos/{id}`：删除任务（204）

## 核心规则
- 全部接口需登录。
- 任务归属按当前登录用户判定。
- 不存在或无权访问返回“任务不存在”。
