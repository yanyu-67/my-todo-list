# 接口总览

统一响应：
```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

## 公开接口
- `GET /api/health`
- `POST /api/auth/register`
- `POST /api/auth/login`

## 受保护接口
- `POST /api/auth/change-password`
- `GET /api/todos`
- `GET /api/todos/{id}`
- `POST /api/todos`
- `PUT /api/todos/{id}`
- `PATCH /api/todos/{id}/complete`
- `DELETE /api/todos/{id}`
