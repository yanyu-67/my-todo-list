# 权限与鉴权

## 安全策略
来源：`backend/src/main/java/com/yanyu/todo/config/SecurityConfig.java`

- 公开：`/api/health`、`/api/auth/register`、`/api/auth/login`
- 其余接口：必须认证
- 会话策略：`STATELESS`

## JWT 处理
来源：`backend/src/main/java/com/yanyu/todo/security/JwtAuthenticationFilter.java`

- 从 `Authorization` 读取 `Bearer token`
- 解析用户名并校验用户存在后写入认证上下文
- token 非法或过期时不设置认证上下文

## 错误响应
- 未登录：`401`，消息“请先登录”
- 无权限：`403`，消息“无权访问该权限”

## 数据隔离
- Todo 查询与修改均按 `userId` 过滤。
- 用户不能访问其他用户任务。
